# Official photography goes here

Drop the hotel’s own photographs into this folder when you have them, then point
`tools/build.js` at them (or copy them over the existing files in `../` using the same names).

Suggested names, matching the pages that need them:

| Filename | Used for |
| --- | --- |
| `exterior.jpg` | Home slider, contact hero, About story image |
| `lobby.jpg` | About hero, gallery |
| `rooftop.jpg` | Home split feature, gallery, journal hero |
| `pool.jpg` | Home split feature, booking hero |
| `restaurant.jpg` | Dining hero and feature |
| `standard-room.jpg` | Standard Room card + page |
| `classic-room.jpg` | Classic Room card + page |
| `standard-suite.jpg` | Standard Suite card + page |
| `classic-suite.jpg` | Classic Suite card + page |
| `apartment-living.jpg` | The Apartment card + page |
| `apartment-kitchen.jpg` | The Apartment gallery |
| `hall.jpg` | Events hero, gallery |

Once official photography is in place, also remove or retire the archive page (`archive.html` and the
`ARCHIVE` array in `tools/build.js`) so nobody compares old Claridon-era photos with current rooms.

See `../../MEDIA.md` for the full list of current (illustrative) and archive images, and why they were used.
